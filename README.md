# DEM Bank

A single-page online banking site with a customer side and a staff back office.

- `index.html` holds the whole site: page, styles and script.
- Customer side: sign up / sign in, accounts with account and routing numbers, transfers between own accounts and to other customers, activity, debit card freeze, settings (details, picture, password, transfer PIN, daily limit, alerts, privacy) and a customer service chat.
- Back office (`Staff sign-in` on the sign-in page): add, edit and delete customers, post transactions, mark customer transfers Pending or Successful, freeze cards, reset passwords and reply to chat messages.

All data is kept in the browser's local storage, so customers and staff must use the same browser. There is no server yet.

To view it, open `index.html` in a browser.
